# WordForge 連續聆聽人工驗收指南

本指南用於驗收瀏覽器與真實裝置上的連續聆聽。前景播放與資料守恆是必要通過項目；背景及鎖屏是否持續播放只記錄觀察結果，不作硬性 PASS gate。

## 驗收前準備

1. 匯入至少一組含 3 張卡片的單字或片語牌組，且每張都有例句。
2. 在學習中心選取該牌組。
3. 先從「設定 → 一般與備份」匯出一份 JSON，作為可恢復的安全備份。
4. 記錄驗收前資料：
   - 今日已練習、困難、良好、輕鬆四個數字。
   - 任選一張卡片的學習狀態、間隔與最後複習日；也可保留匯出的 JSON 供前後比對。
5. 進入「連續聆聽」，設定主內容 3 次、例句 2 次、依序、不循環。

## 所有平台共同必要項目

- [ ] 進入時保持暫停，沒有自動發聲。
- [ ] 按播放後依序朗讀「主內容 3 遍 → 例句 2 遍 → 下一張」。
- [ ] 暫停後不繼續朗讀；恢復後從目前階段繼續。
- [ ] 上一張、下一張與播放清單跳轉到正確卡片。
- [ ] 主內容或例句設為 0 時會略過該階段；兩者至少一項大於 0 時可播放。
- [ ] 關閉並重新進入後回到上次卡片，但仍保持暫停。
- [ ] 播放後四張統計數字與驗收前完全相同。
- [ ] 再匯出 JSON，比對 `cards` 與 `reports` 和驗收前相同；允許 `settings.listeningPreferences` 改變。

## Windows Chrome 與 Edge

每個瀏覽器各驗收一次：

- [ ] 3／2 連播順序與卡片間隔正常。
- [ ] 播放、暫停、恢復、上一張、下一張正常。
- [ ] 未勾循環時在最後一張顯示播放完成。
- [ ] 勾選循環後，最後一張結束會回到第一張。
- [ ] 320、390、430、768、1024、1440px 開發者工具寬度下無水平捲動，底部控制列不遮住內容。

## Android Chrome

先在一般瀏覽器頁籤驗收，再將 WordForge 安裝為 PWA 重複一次：

- [ ] 前景 3／2 連播、暫停與上一張／下一張正常。
- [ ] 播放中切到其他 App 30 秒，記錄是否持續：`持續／中斷／其他：________`。
- [ ] 回到前景時若語音已中斷，畫面顯示中斷提示且不自動發聲。
- [ ] 再按播放會從目前這一遍重新開始，而不是跳過該遍。
- [ ] 直式與橫式都沒有水平溢位，底部按鈕可完整點擊。

## iPhone Safari

先在 Safari 驗收，再以「加入主畫面」的 PWA 重複一次：

- [ ] 只有使用者按下播放後才開始發聲。
- [ ] 前景 3／2 連播、暫停與上一張／下一張正常。
- [ ] 播放中鎖屏 30 秒，記錄是否持續：`持續／中斷／其他：________`。
- [ ] 解鎖回到前景後若已中斷，播放器不自動發聲。
- [ ] 再按播放會重播目前這一遍。
- [ ] Safari 工具列展開／收合與直橫向切換時，safe-area 不遮住控制列。

## 斷網與語音來源

1. 先載入 WordForge，進入連續聆聽後關閉網路。
2. 使用裝置內建 voice：
   - [ ] 可繼續播放，或在平台限制下顯示可恢復錯誤。
3. 若該語言只有 online voice：
   - [ ] 失敗後顯示重試、跳過卡片與返回操作。
   - [ ] 恢復網路後按重試可以繼續；系統不會自行無限重試。
4. 斷網期間播放仍不得修改 `cards` 或 `reports`。

## 音訊設定逐平台驗收

### Windows Chrome / Edge

1. 開啟連續聆聽 → 音訊設定。
2. 記錄 Chrome 與 Edge 各自顯示的 voice 名稱。
3. 逐一選擇八個倍速並試聽,確認摘要與實際 request 一致。
4. 播放中改速,確認目前這一遍不中斷、下一遍才套用。

### Android Chrome / PWA

1. 確認初次開啟時 loading 最終結束。
2. 切換本機／可能需網路 voice,斷網後確認失敗可恢復且不會無限重試。
3. 背景再回前景,確認保持暫停並由使用者手勢恢復。

### iPhone Safari / PWA

1. 以點擊試聽啟動語音,確認不嘗試自動播放。
2. 鎖屏再返回,確認舊 callback 不推進卡片。
3. 若首選 voice 不存在,確認顯示原名稱與「目前無法使用」,正式播放仍可 fallback。

### 跨 Profile / 裝置

1. 匯出含首選 voice 的完整備份。
2. 在沒有該 voice 的 Profile 匯入。
3. 確認倍速保留、首選名稱仍顯示、播放使用相容 fallback。
