# WordForge — 高品質單字學習系統 🚀

[![README](https://img.shields.io/badge/README-English-blue.svg)](./docs/i18n/README-en.md)
[![Data Spec](https://img.shields.io/badge/Data%20Spec-v1.1-green.svg)](./docs/SPEC.md)
[![PWA](https://img.shields.io/badge/PWA-offline%20ready-5a67d8.svg)](#-安裝與存取)

一個為進階學習者設計的極簡單字卡系統,具備精確的 SRS(間隔重複)演算法、多語系介面,以及隱私優先的離線體驗。

## ✨ 核心功能
*   **單字／片語雙模式**:入口頁可選擇背單字或練片語;片語卡聚焦英文片語、例句、中文解釋與例句翻譯。
*   **多語系架構與介面**:支援 8 種介面語言(繁中、英、日、韓、德、西、法、泰),並為各語言提供專屬卡片排版(如日語假名/漢字、德語文法性、泰語聲調)。
*   **完整語音朗讀 (TTS)**:單字與**例句**皆可朗讀,強化聽力。
*   **連續聆聽模式**:可設定單字／片語與例句各朗讀 0～5 次,支援今日／全部、依序／隨機、循環及播放清單跳轉,且不改動 SRS 進度。
*   **個人化主題系統**:提供 3 組淺色、3 組深色推薦主題,支援跟隨系統、即時預覽、HEX／調色盤自訂與 WCAG 對比保護。
*   **可調整版面與圖標**:可用「−／百分比輸入／＋」在安全範圍內調整八種文字／圖標倍率,並保存 3 組可命名的自訂圖標;每張圖可在框內縮放與拖曳定位。
*   **可攜資料備份**:可把設定、自訂圖標、牌組、卡片 SRS 進度與報表匯出為含版本與完整性 hash 的 JSON,並在匯入前先驗證內容。
*   **選用式 Google Drive 同步**:可由設定頁主動連結自己的 Google Drive 隱藏應用程式資料夾;使用最小 `drive.appdata` 權限、記憶體短效 token、離線續用與衝突保全。
*   **漸進式網頁應用 (PWA)**:可安裝到手機與桌面,提供全螢幕、離線的原生體驗。
*   **本機優先與離線 (IndexedDB)**:牌組與學習進度先存於瀏覽器本地,無需登入也能離線使用;只有使用者主動連結 Google Drive 後才會同步。
*   **高品質 CSV 匯入**:支援符合 [資料規格](./docs/SPEC.md) 的單字 9 欄位與片語 5 欄位 CSV,並能自動偵測語系與牌組類型。

## 📲 安裝與存取

### 1. 網頁版直接使用(最快)
[開啟 WordForge Web App](https://shuai-chi.github.io/wordcards/)
*   純前端應用,載入後即可離線使用;資料預設只存在瀏覽器,Google Drive 同步為選用功能。

### 2. 手機安裝(建議 PWA)
*   **iOS (Safari)**:點「分享」→「加入主畫面」。
*   **Android (Chrome)**:點選單 →「安裝應用程式」。

### 3. 本地開發
```bash
git clone https://github.com/Shuai-chi/wordcards.git
cd wordcards
npm install
npm run dev -- --host 0.0.0.0
```

若專案在 WSL2 內執行,可直接從 Windows Chrome／Edge 開啟 `http://localhost:5173`;不需要把專案複製到 Windows 檔案系統。若 Windows 的 localhost 轉送暫時失效,請以 `npm run dev -- --host 0.0.0.0` 啟動,再用 `hostname -I` 顯示的 WSL IP 開啟 `http://<WSL-IP>:5173`;備份匯出與配色複製支援這種非安全來源預覽。Google OAuth 驗收例外:網址必須與 Cloud Console 的 Authorized JavaScript origin 完全相同,請使用 `http://localhost:5173` 或已登記的 HTTPS 部署網址,不要用臨時 WSL IP 驗收登入。

## 🛠️ 使用教學

### 第一步:準備與匯入
1.  **選擇模式**:在入口頁選擇「背單字」或「片語」,進入對應的學習中心。
2.  **取得牌組**:可直接使用 [`sample-decks/`](./sample-decks) 內的範例牌組(GRE / TOEFL / 高中 CEFR 分級／日常片語),或依 [資料規格](./docs/SPEC.md) 自行產生 CSV。
3.  **匯入**:點右上角的「上傳」圖示並選擇 CSV;系統會自動偵測語系與單字／片語類型。

### 第二步:設定
1.  **固定操作列**:設定名稱、頁籤、儲存與關閉按鈕固定在視窗上方;只有分頁內容會捲動。儲存成功後視窗保持開啟並顯示「已儲存」;有未儲存變更時,按 X、點外側或按 Escape 都會先詢問要回到編輯或捨棄離開。
2.  **外觀**:在「設定 → 外觀」選擇跟隨系統、淺色或深色模式,再套用推薦主題;也可自訂品牌色、強調色、背景色與卡片色。自訂配色上方的 AI 色彩指令列採固定英文鍵,格式為 `background=#RRGGBB;card=#RRGGBB;primary=#RRGGBB;accent=#RRGGBB`;下方會顯示 `background=背景、card=卡片、primary=主色、accent=強調` 對照,也可只填要修改的項目。打勾只更新即時預覽,仍須按頂部「儲存」才會寫入本機。可顯示／複製目前完整配置,回復按鈕則回到最近一次儲存的目前模式配色。
3.  **尺寸微調**:在同一頁籤用減號、可輸入百分比與加號調整基礎文字、頁面標題、卡片標題、說明文字、統計數字、卡片圖標、練習卡主詞與練習卡答案倍率;固定的「網站介面＋練習卡」雙預覽會立即反映每項變更,並提供單項與全部重設。
4.  **自訂圖標**:在「設定 → 圖標」切換或重新命名 3 組圖片設定。名稱輸入期間可暫時留空,只有儲存時仍為空白才恢復「設定 1／2／3」。六種圖標皆可上傳 PNG／JPG／WebP(每張最多 512 KiB),並可完整適應、填滿、縮放、拖曳或個別移除;固定預覽會顯示目前組合與圖片位置。
5.  **可讀性保護**:若自訂配色未達文字／控制項對比標準,系統會顯示問題組合並暫停儲存。
6.  **全域每日上限**:在「設定 → 一般與備份」設定每日跨所有牌組的新卡上限;也可為各牌組單獨設定每日新卡數。
7.  **備份與還原**:在「設定 → 一般與備份」匯出 JSON;匯入時會先顯示套牌、卡片與報表筆數,確認後才取代現有資料。schema v3 包含尺寸、自訂圖標與連續聆聽偏好,舊版 v1／v2 備份仍可匯入;驗證或套用失敗會保留原資料。
8.  **Google Drive 同步(Pilot)**:在「設定 → 一般與備份」主動連結 Google Drive。首次授權與短效 token 過期時需由使用者按鈕操作;連結後會在本機變更、恢復網路或回到前景時同步,也可按「立即同步」。斷開連結不會刪除本機或雲端資料;「刪除雲端備份」會二次確認、只永久刪除 WordForge 建立的雲端快照並保留本機資料。若偵測到兩端分岔,系統保留各份資料與衝突快照,不依裝置時間靜默覆蓋。

### 第三步:練習(SRS 機制)
系統依你的反饋安排下次複習:
*   **Again (1)**:完全忘記。卡片進入重學,稍後再次出現。
*   **Hard (2)**:想得起來但很慢。縮短下次間隔。
*   **Good (3)**:順利想起。以標準間隔成長。
*   **Easy (4)**:輕鬆答對。大幅延長間隔。

### 第四步:連續聆聽
在學習中心選好牌組後,點「進入聆聽模式」。此模式只讀取所選牌組,不會建立評分或改變 SRS 進度。可設定單字／片語與例句各播放 0～5 次,並選擇今日清單／全部卡片、依序／隨機及整份循環。

- 播放速度:0.5×、0.75×、0.85×、1×、1.25×、1.5×、1.75×、2×,預設 0.85×。
- 首選聲音來自目前瀏覽器／作業系統;換裝置找不到或語言不相容時會自動備援。
- 變更速度或聲音不會中止目前正式朗讀,下一遍開始套用;「試聽」會中止目前這一遍並保持暫停。

前景播放是正式支援目標;切換 App、鎖屏或系統休眠後能否持續,由瀏覽器與作業系統決定。若系統中斷語音,回到前景後會停在目前這一遍並提示重新播放,不會自行發聲。重新開啟會回到上次卡片但保持暫停,仍需按播放。各平台實機檢查方式見[連續聆聽人工驗收指南](./docs/continuous-listening-manual-qa.md)。

### 第五步:重練今日卡片
完成每日任務後,開始按鈕會變成「**重複練習今日**」,可在不影響長期 SRS 排程下鞏固當天所學。

## 📂 專案結構
*   `src/components/`:UI 組件(Dashboard、LearningView 等)。
*   `src/lib/`:核心邏輯(SRS 演算法、CSV 解析、語言偵測、IndexedDB)。
*   `docs/`:多語系 README 與 [資料規格](./docs/SPEC.md)。
*   `prompts/`:用 AI 產生單字卡的提示詞與格式說明。
*   `sample-decks/`:可直接匯入的範例 CSV 牌組。

## 🛡️ 隱私聲明
WordForge 是本機優先、隱私優先(Privacy-First)的工具。主題、尺寸、圖標設定名稱與連續聆聽偏好保存在瀏覽器 `localStorage`;自訂圖片、牌組與學習進度保存在 IndexedDB。沒有主動連結 Google Drive 時,資料不會離開瀏覽器。

主動連結 Google Drive 後,完整備份會同步到該 Google 帳號中只供 WordForge 存取的隱藏 `appDataFolder`,內容包含設定、牌組、卡片原文、SRS 進度、報表與自訂圖標。程式只要求 `drive.appdata` 權限;access token 只存在記憶體,不保存 Client Secret、refresh token,也不新增 WordForge 後端。斷開連結不等於刪除資料;永久刪除雲端備份另有二次確認。清除瀏覽器資料仍可能刪除尚未同步的本機變更,因此**請定期從「設定 → 一般與備份」匯出 JSON 並妥善保存**。

程式端 Google Drive Pilot 已完成;正式認定跨裝置可用前仍需通過真實 Google 帳號的兩瀏覽器 Profile 驗收。完整設定、secret 撤銷、WSL2、離線與衝突步驟請見 [WordForge 雲端同步驗證指南](../WordForge_雲端同步驗證指南.html)。
