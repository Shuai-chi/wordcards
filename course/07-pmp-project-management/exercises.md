# Module 7 練習題

## 練習 1:專案章程
為 Capstone 專案(AI 智慧客服系統)寫一份簡短的專案章程,包含:
- 專案目的(一句話說明為什麼要做)
- 成功標準(例如「機器人能正確回答 80% 的測試問題」)
- 主要利害關係人與他們的期待
- 高層級範疇(包含什麼、明確不包含什麼)

## 練習 2:WBS
參考本模組教材的 WBS 範例,依你自己 Capstone 專案的實際規劃,寫出至少三層的 WBS,每個最底層任務估算所需工時(小時或天)。

## 練習 3:風險登記表
列出至少 8 項你 Capstone 專案可能遇到的風險,每項包含:發生機率(高/中/低)、影響程度(高/中/低)、應對策略(規避/降低/轉移/接受)、負責人(自學者就是你自己,但練習「指派」的思維)。

## 練習 4:甘特圖 / 時程規劃
用 Excel、Google Sheets 或線上工具(例如 [Instagantt](https://www.instagantt.com/) 免費版)畫出 Capstone 專案的甘特圖,標示各任務的開始/結束日期與相依關係(例如「LINE Bot 開發」必須在「ChatGPT API 整合完成」之後才能開始)。

## 挑戰題(選做)
比較「用瀑布式規劃 Capstone 專案」與「用兩週一個 Sprint 的 Scrum 方式規劃」兩種做法的時程表差異,寫下你觀察到的優缺點。
