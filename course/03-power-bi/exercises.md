# Module 3 練習題

## 練習 1:資料清理
找一份含有髒資料的 CSV(可自己在 Excel 造 20–30 列,故意包含空白列、重複列、日期格式不一致的欄位),用 Power Query:
1. 移除空白列與重複列
2. 統一日期欄位格式
3. 把「姓名(部門)」欄位拆成「姓名」與「部門」兩欄

## 練習 2:建立資料模型
匯入 Module 2 的 `bookstore.db`(或匯出成 CSV 匯入),在 Power BI 中:
1. 建立 `books`、`authors`、`orders` 三張表的關聯
2. 寫出以下量值(Measure):
   - `Total Revenue`(總營收 = 訂單數量 × 書籍單價,加總)
   - `Total Orders`(總訂單數)
   - `Average Order Value`(平均訂單金額)

## 練習 3:互動式儀表板(整合練習)
用練習 2 的資料模型,設計一份包含以下元素的儀表板:
1. 一張顯示「每月營收趨勢」的折線圖
2. 一張顯示「各作者營收排行」的長條圖
3. 一個可依「出版年份」篩選的 Slicer
4. 至少 2 張 KPI 卡片(例如總營收、總訂單數)
5. 確認點擊長條圖某位作者時,折線圖會連動篩選只顯示該作者的月趨勢

## 挑戰題(選做)
用 DAX 寫出「本月 vs 上月營收成長率」量值,並用條件格式(Conditional Formatting)讓成長率為負時顯示紅色、為正時顯示綠色。
